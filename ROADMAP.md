# Roadmap

## Phase 1: Public Benchmark Baseline

- Maintain a compact approval-execution drift corpus.
- Maintain the 6,000-record runtime boundary corpus.
- Keep the runner dependency-light and easy to inspect.
- Generate Markdown and JSON reports.
- Generate CSV tables for report design and external review.
- Add CI for benchmark execution.

## Phase 2: Runtime Importers

- Import MCP tool-call records.
- Import browser automation traces.
- Import n8n workflow execution records.
- Import Dify workflow/tool-call records.
- Import local agent hook records.

## Phase 3: Expanded Controls

- Add policy pack examples.
- Add rollback-path classification.
- Add identity-boundary classification.
- Add external verifier examples.
- Add optional CAVA package integration.

## Phase 4: Community Review

- Expand beyond 6,000 records with community-contributed runtime traces and adapter packs.
- Add external contributor cases.
- Map cases to OWASP GenAI and agentic AI security categories.
- Prepare OWASP project submission.
- Prepare Black Hat Arsenal submission and demo video.

## Phase 5: Public Validation

- Add a small anonymized real-trace corpus where contributors can legally share records.
- Add adapter-quality scoring for runtime importers.
- Add reviewer-friendly artifact bundles for OWASP, Black Hat Arsenal, and academic artifact review.
- Publish periodic benchmark reports with fixed seeds and versioned corpora.
